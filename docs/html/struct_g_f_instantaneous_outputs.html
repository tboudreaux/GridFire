Detailed Description

Destinations for the instantaneous final-state quantities in NetOut.

For a point context each scalar pointer refers to a single double; for a grid context each refers to an array with one entry per zone. eps_by_channel holds the channel energies of each zone contiguously (eps_by_channel[zone * num_channels + channel]).
