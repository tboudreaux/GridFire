std::string gridfire::describe_provenance ( const config::GridFireConfig & config,
const engine::DynamicEngine * engine = nullptr,
engine::scratch::StateBlob * ctx = nullptr,
std::string_view policy_name = {} )
nodiscard

A description of the physics a GridFire calculation uses, for a host code to record with its results.

One "key: value" line per item: GridFire version, network policy, network size and hash, the rate libraries and the hashes of their compiled data, screening, Jacobian method, passive species, energy channels and solver tolerances. The network lines are omitted when engine is null (no network built yet).

Two runs that print the same description used the same code version, rates, network and physics options.

◆ gf_config_main()

int gridfire.gf_config_main ( argv = None) 
gf-config: print what a build needs to use this GridFire installation.

Examples:
    gf-config --cflags --libs                      # C++ library
    gf-config --component c --cflags --libs        # C API (gridfire/extern/gridfire_extern.h)
    gf-config --component fortran --libs           # Fortran: link flags
    gf-config --fortran-source                     # Fortran: the module source to compile with your compiler
    PKG_CONFIG_PATH=$(gf-config --pkg-config-path) pkg-config --cflags --libs gridfire_extern
    cmake -DCMAKE_PREFIX_PATH="$(gf-config --cmake-prefix)" ...   # then find_package(GridFire)
