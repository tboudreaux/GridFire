Detailed Description

Each pair's exponent and partials at one plasma state, kept per thread: the engine (and BlendedScreeningModel) asks for the factors, composition derivatives and state derivatives at the same state in separate calls, and each pair is shared by several reactions. Keyed by the model instance and everything the exponents depend on (T9, rho, Y_e and zeta), so a different state, or another model instance, starts afresh.
