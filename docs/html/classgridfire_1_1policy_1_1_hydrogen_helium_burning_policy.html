Detailed Description

A fixed network for hydrogen and helium burning, from the main sequence through core and shell helium burning (HydrogenHeliumReactionChainPolicy: pp chains, CNO cycle, triple-alpha and the alpha captures).

Unlike MainSequencePolicy, the network does not depend on the starting composition: it is always built (to third order) from the same seed species (H-1, He-3, He-4, C-12, N-14, O-16, Ne-20, Mg-24), so a run started from a pristine composition already contains every helium-burning species and reaction it will need, and two runs with different compositions have the same species in the same order. The composition passed in only has to lie within that network; no species is required, so callers that do not track Ne-20 or Mg-24 can leave them out.

construct() verifies the network contains every reaction of HydrogenHeliumReactionChainPolicy.
