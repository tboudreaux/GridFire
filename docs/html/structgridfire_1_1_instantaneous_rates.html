Detailed Description

Instantaneous rates at one state (composition, T, rho), with nothing integrated.

Returned by SingleZoneNetworkSolver::evaluateRates and MultiZoneNetworkSolver::evaluateRates, and what the C API's gf_evaluate reports. eps_nuc, dEps_dT and dEps_dRho match the final-state values evolve() reports for the same state.
