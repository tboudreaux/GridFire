Detailed Description

Run-time configuration, the C mirror of gridfire::config::GridFireConfig (field names follow its nesting).

Start from gf_config_defaults, change what you need, and pass it to gf_set_config before gf_construct_engine_from_policy. Booleans are ints (0 = false). The energy channel fuel list has no field here; it keeps its current value (the default, or what gf_load_config read).

Fortran: type(GFConfig) in gridfire_mod has the same layout.
