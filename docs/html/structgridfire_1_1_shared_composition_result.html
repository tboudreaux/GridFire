Detailed Description

Result of burning one composition shared by several shells (SingleZoneNetworkSolver::evaluateSharedComposition).

The composition evolves as dY/dt = sum_i w_i f(Y, T_i, rho_i); the energy and neutrino losses of each shell are integrated alongside at that shell's own T and rho.
